# Check2Go screen exports

Source: [Check2Go / Screens in Figma](https://www.figma.com/design/FVVplMUExRWDAY1npMxRmj/Check2Go?node-id=1-26200).

Exported on 2026-09-13 using the connected Figma module. All 49 top-level screen frames on the Screens page are included, in Figma layer order. Original names, configured image formats and export resolutions are preserved. Similar names represent separate frames or states; node IDs make filenames unique. Standalone annotation text outside screen frames is not exported.

These are static visual snapshots. The editable design remains in Figma; this folder is not a `.fig` backup. Existing historical variants are included without selecting a preferred implementation.

See [manifest.json](manifest.json) for original frame dimensions and individual source links.
