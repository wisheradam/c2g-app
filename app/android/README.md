# Check2GO Android

Native Android target for Check2GO.

## Target stack

- Kotlin
- Jetpack Compose
- Android SDK
- AWS backend integration through AppSync/Cognito APIs
- Local persistence to be selected during rebuild (Room is the default candidate)

## Recovery source

The historical Flutter APK remains a behavioral and architectural reference only. Android implementation will be rebuilt natively.

## Current package reference

Historical Android package: `co.check2go`.
