# Historical Flutter Reference

The previous Check2GO client was built with Flutter/Dart.

This folder documents Flutter-specific findings recovered from APKs and other historical materials. Flutter is no longer the target implementation strategy.

Use these findings to recover:
- screen structure and navigation
- business behavior
- local data model clues
- assets and localization
- backend integration behavior
- reminders, documents, OCR and people/travel flows

Do not treat the historical Flutter structure as mandatory architecture for the new native Android and iOS applications.
